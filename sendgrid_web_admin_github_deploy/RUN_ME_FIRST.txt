1. Double click install_all_safe.bat
2. Edit .env:
   ADMIN_PASSWORD
   SECRET_KEY
   DATA_ENCRYPTION_KEY
   SERVICE_TOKEN
3. Double click start_web_admin.bat
4. Open http://127.0.0.1:8080
5. Login as admin, then open 团队成员 to add team members.
6. Open 收件人 and upload one or multiple TXT/CSV files to the single recipient pool.
   Named lists are filters of this pool, not additional pools.
7. Open HTML 模板. Enter a subject and sender display name when uploading HTML
   files. The values are bound to every file in that upload and can then be
   edited per file. The sender email address comes from the selected API channel.
8. Create a fixed 30-day task or a custom warm-up task and select a template group.
   A custom warm-up task may use the full pool or a named-list filter.
9. Generate or start the plan. The system reserves eligible recipients from the
   single pool. If stock is insufficient, it does not create a partial plan.
10. Existing tasks, scheduled messages and send history remain available after upgrade.
    Old template files without bindings use the task subject and channel sender name.

Warm-up speed:
Day 1 <= 60, actual 45-60
Day 2 <= 200, actual 185-200
Day 3 <= 700, actual 685-700
Day 4-30 <= 1000/day, actual 985-1000/day

Recipient pool upload supports multi-file selection with configurable safety limits.
